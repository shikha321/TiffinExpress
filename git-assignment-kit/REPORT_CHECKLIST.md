# PDF Report Checklist

1. **Cover page:** project title, both names and roll numbers.
2. **Repository and features:** GitHub link and the five features.
3. **Individual contributions:** a table of who built what, with commit counts.
4. **Git evidence (screenshots):**
   - Repo created and collaborator invited
   - Branches list
   - Commit history and `git log --oneline --graph --all`
   - Both pull requests
   - Both reviews and approvals
   - Merge conflict (markers) and its resolution
5. **Application screenshots:** login, menu, cart with coupon, order tracking, admin dashboard.
