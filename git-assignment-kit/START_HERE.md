# Tiffin Express Git Assignment — Start Here

This package is organized to follow `GIT_GUIDE.md`. It contains the starter project, each student's split commit parts, the finished app for testing, and the report checklist.

## Folder map
- `project/` — Student 1 copies this folder's contents into the GitHub repository first. This is the starter/base project.
- `commit-parts/student1/` — Student 1's code parts, used to create the required small commits on `feature-member1`.
- `commit-parts/student2/` — Student 2's code parts, used to create the required small commits on `feature-member2`.
- `full-working-project/` — complete app for local testing and screenshots; use it for reference/testing, not as a substitute for the staged commits.
- `GIT_GUIDE.md` — step-by-step Git commands and PR/merge-conflict workflow.
- `REPORT_CHECKLIST.md` — required evidence for the PDF report.

## Student split

### Student 1 — `feature-member1`
1. Repository setup and initial `main` commit (from `project/`).
2. Login/registration: `commit-parts/student1/01-auth-part1.js` then `02-auth-part2.js`.
3. Cart, coupon, bill and checkout form: `commit-parts/student1/03-cart.js`.
4. Update the Student 1 section in `CONTRIBUTING.md`.
5. Make the four commits specified in `GIT_GUIDE.md`, push branch, open a PR, review Student 2's PR.

### Student 2 — `feature-member2`
1. Clone the repository after Student 1 pushes `main` and invites them.
2. Order placement: `commit-parts/student2/01-orders-part1.js` then `02-orders-part2.js`.
3. Admin dashboard: `commit-parts/student2/03-admin.js`.
4. Update the Student 2 section in `CONTRIBUTING.md`.
5. Make the four commits specified in `GIT_GUIDE.md`, push branch, open a PR, review Student 1's PR.

## Important
- Follow the commands and commit messages in `GIT_GUIDE.md` in order; do not combine the staged code parts into one commit.
- Replace sample names, roll numbers, GitHub usernames and repository URL in the documentation.
- Capture your own screenshots as evidence. Do not submit placeholder screenshots as if they were real.
- The merge-conflict demonstration must be done on two branches created from the same `main` state, as described in the guide.
- Admin credentials are demo-only: `admin@tiffin.in` / `admin123`. Do not use real passwords.
