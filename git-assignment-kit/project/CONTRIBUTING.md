# Contributing Guide

## Branches
| Branch | Owner | Purpose |
|---|---|---|
| `main` | Both | Stable, reviewed code only |
| `feature-member1` | Student 1 | Login, registration and cart |
| `feature-member2` | Student 2 | Orders and admin dashboard |

## Workflow
1. Create a branch from `main`.
2. Make small commits with clear messages (`feat:`, `fix:`, `docs:`).
3. Push the branch and open a pull request.
4. Your partner reviews and approves it.
5. Merge into `main`, then pull the latest `main`.

## Code Review Checklist
- The code runs without console errors.
- Names and comments are clear.
- Only the files related to the feature changed.
